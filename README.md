# Open Smart Home Devroom — FOSDEM 2027 CFP

Static GitHub Pages site for the FOSDEM 2027 Open Smart Home Devroom Call for Papers.

## Publish

Place the contents of this folder in the repository root and publish GitHub Pages from `main` / `/ (root)`.

## Files

- `index.html` — single-page CFP site
- `styles.css` — responsive styling
- `assets/logo.svg` — devroom logo
- `assets/joost.jpg`, `maarten.jpg`, `arjen.jpg` — organiser photos

## To update once FOSDEM Pretalx opens

Replace the disabled submission button in `index.html` with the official FOSDEM 2027 Pretalx URL.
